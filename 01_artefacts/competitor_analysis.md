## 2. Яндекс — главный конкурент

**Сильные стороны**
- Собственные технологии: SpeechKit, YandexGPT, поисковый API — не зависят от внешних моделей.
- Бренд и доверие, пилот с Департаментом здравоохранения Москвы.
- Закрывает требования безопасности (152-ФЗ, УЗ-1), есть облако и on-premise.
- Бесплатный ассистент для врачей (поиск рекомендаций, калькуляторы, проверка лекарств; веб и мобильное приложение): быстрая дистрибуция и привычка у врачей.
- Три модуля: протокол + база знаний + поиск по ЭМК — шире, чем простая расшифровка.

**Слабые стороны / пространство для нас** (гипотезы)
- Универсальный продукт: протокол собирается через конструктор полей, глубокая подстройка под специальность и стандарт клиники может требовать усилий.
- Нет данных, с какими МИС работает интеграция частных клиник и сколько она стоит.
- Цена и условия для клиник не раскрыты: непонятно, как закупает средний сегмент.
- Крупная компания: медленнее реагирует на запросы отдельных сетей, персональный онбординг и пилот «под ключ» дороги.

## 3. Остальные игроки

- **Клиентикс**: преимущество — встроенность в МИС, которой пользуются 1 000+ клиник, оплата за использование без подписки. Слабость: работает только внутри своей экосистемы, клиникам на других МИС недоступен. Это **ближайший по ЦА конкурент** (частные клиники).
- **Ленивый доктор**: заточен под on-premise и интеграцию с МИС сетей, есть пилот в «Будь Здоров». Масштаб и цена неизвестны.
- **Московский проект**: закрывает госсегмент, поэтому для нас он не конкурент по ЦА, но формирует ожидания врачей и пример эффекта.
- **Зарубежные**: ориентир по цене и функциям, в РФ недоступны.

## 4. Сравнение по критериям для ЛПР частной клиники

| Критерий | Яндекс Мед | Клиентикс | Ленивый доктор | Что нужно нам |
|---|---|---|---|---|
| Голосовой протокол | ✓ | ✓ | ✓ | ✓ (базовый уровень) |
| Работает с любой МИС | неизвестно | ✗ (своя МИС) | ✓ (заявлено) | ✓ — возможное преимущество |
| On-premise | ✓ | ✗ (серверы в РФ) | ✓ | по запросу |
| Безопасность 152-ФЗ | ✓ | ✓ | неизвестно | обязательно |
| Цена понятна | ✗ | ✓ (токены) | ✗ | прозрачная подписка |
| Подстройка под специальность | через конструктор | неизвестно | неизвестно | возможное преимущество |
| Эффект доказан цифрами | заявлен (−40%) | заявлен | заявлен (−50%) | нужны свои пилоты |

## 5. Выводы и возможное позиционирование

1. **Рынок уже занят**: голосовой протокол — не уникальная функция, к осени 2026 есть Яндекс, Клиентикс, Ленивый доктор. Только «сделаем протокол по голосу» не отстроит.
2. **Возможные углы отстройки** (проверять интервью): подстройка под специальность и стандарты конкретной сети, работа с любыми МИС, понятная цена и пилот с измеримым результатом (минуты на врача, число приёмов), работа с сопротивлением врачей (обучение, внедрение).
3. **Угроза**: бесплатный ассистент Яндекса и модуль в МИС Клиентикс делают порог входа низким. Нужен аргумент, почему клинике платить нам.
4. **Следующие шаги**: узнать цену и условия Яндекса для клиник; тест конкурентов вживую (демо Клиентикс, доступ к Яндекс Мед); интервью с 3–5 главврачами о том, что они уже пробовали.
