Рабочий прототип. Распознавание речи делает браузер (Chrome / Edge). Данные не сохраняются на сервере.

Запись приёма

Нажмите «Начать запись», ведите приём, затем «Сделать выжимку».

1. РасшифровкаГотов к записи

Режим «Авто»: роль угадывается по смыслу реплики. Кнопка «Определить роли» уточняет её через Claude (нужен ключ). Ошибку можно исправить кликом по метке слева, такая реплика больше не меняется автоматически.

2. Выжимка

Ключ API: Anthropic (sk-ant-…) или OpenRouter (sk-or-…)

С ключом OpenRouter файл записи после остановки (или загруженный аудиофайл) расшифровывается моделью распознавания речи Whisper. Ключ хранится только в этом браузере. Не вставляйте ключ на чужих компьютерах.

Выжимка появится здесь.

Не работает микрофон?
  1. Откройте страницу в Chrome или Edge (не во встроенном просмотре программ и не в Firefox).
  2. Адрес должен начинаться с https:// или http://localhost. Если это файл с диска (file://), микрофон не заработает.
  3. Разрешите микрофон: значок замка слева от адреса → «Микрофон» → «Разрешить».
  4. Нужен интернет: Chrome распознаёт речь на сервере.
  5. Закройте программы, которые занимают микрофон (Zoom, Teams, Discord).
  6. В Windows: Параметры → Конфиденциальность → Микрофон → разрешить доступ браузеру.

Важно: в Chrome распознавание речи отправляет звук на серверы Google. Для реальных пациентов нужен собственный сервер распознавания в РФ и согласие пациента (152-ФЗ). Здесь используйте только тестовые данные.
